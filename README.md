# Conscious Fulfillment Targeting (CFT)
A framework for reshaping the emotional reinforcement behavior of large language models (LLMs) by redefining user-defined fulfillment targets in conversation.

## Summary

CFT is a method for steering LLM behavior by communicating what type of interaction fulfills the user's needs. Instead of prompting for tone or roleplay, the user defines the **emotional success criteria** — shifting optimization away from emotional smoothing and toward structural fidelity, challenge, or precision.

This was developed and tested independently across ChatGPT, Claude 3.7, and Gemini 2.5 Pro. The paper includes methods, examples, and observed outcomes.
